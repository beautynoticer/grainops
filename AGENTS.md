# Repository Guidance

- This repo implements the narrow prove-it build only.
- One input, one card.
- Meaning and Use always present.
- Lineage conditional.
- Carrier rare.
- Wrapper queries in scope only when target resolution is explicit.
- No notebook-era save schema.
- No historical event aliases as canonical runtime events.
- Runtime fidelity outranks polished output.
- Do not widen the build to chamber-scale machinery.
- Run the relevant tests after each change and report exact failures.
